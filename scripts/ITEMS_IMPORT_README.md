# Импорт стандартных предметов

## Описание
Система автоматического импорта предметов из папки `scripts/standard_items`. При создании/пересоздании базы данных все предметы из этой папки автоматически импортируются с парсингом их названий и наград.

## Формат названий файлов

```
РЕДКОСТЬ_НАЗВАНИЕ_НАГРАДЫ.png
```

### Компоненты:
- **РЕДКОСТЬ**: обычная | необычная | редкая | эпическая | легендарная
- **НАЗВАНИЕ**: название предмета (может содержать пробелы через подчеркивания)
- **НАГРАДЫ**: награды через подчеркивания в формате:
  - `Nм` - N монет
  - `Nои` - N очков интеллекта
  - `Nуд` - N удовлетворенности

### Примеры:
```
Легендарная_Ключ логики_15ои_7м_9уд.png
  → Название: "Ключ логики"
  → Редкость: legendary
  → Награды: 15 ОИ, 7 монет, 9 удовлетворенности

Обычная_Искра знания_1ои.png
  → Название: "Искра знания"
  → Редкость: common
  → Награды: 1 ОИ

Редкая_Ключ ясности_6м_3уд.png
  → Название: "Ключ ясности"
  → Редкость: rare
  → Награды: 6 монет, 3 удовлетворенности
```

## Использование

### 1. Добавление новых предметов
1. Поместите изображение в папку `scripts/standard_items/`
2. Назовите файл по формату выше
3. Пересоздайте базу данных

### 2. Пересоздание базы данных
```bash
# Через API
curl -X POST http://localhost/api/user/reset-db

# Или через скрипт
./reset-db.sh
```

### 3. Тестирование парсера
```bash
cd scripts
python import_standard_items.py
```

## Структура данных

После импорта предметы сохраняются в базе данных с полями:
- `name` - название предмета
- `description` - автогенерируемое описание
- `rarity` - редкость (enum)
- `type` - всегда "consumable" для стандартных предметов
- `base_price` - базовая цена (= награда в монетах)
- `reward_coins` - награда в монетах
- `reward_intelligence_points` - награда в очках интеллекта
- `reward_satisfaction` - награда в удовлетворенности
- `image_filename` - имя файла изображения

## Доступ к изображениям

Изображения доступны через API:
```
GET /api/inventory/items/image/{filename}
GET /api/inventory/static/items/{filename}
```

## Файлы системы импорта

- `scripts/import_standard_items.py` - парсер названий файлов
- `services/user_service/main.py` - логика импорта в /reset-db
- `services/shared/models/item.py` - модель Item с наградами
- `services/inventory_service/main.py` - API для работы с предметами
- `docker-compose.yml` - volumes для static файлов

## Технические детали

### Volumes
```yaml
volumes:
  - ./scripts:/app/scripts:ro        # user-service (readonly)
  - static_files:/app/static         # shared между сервисами
```

### Директории
```
/app/static/items/          # Изображения предметов
/app/scripts/standard_items/ # Исходные файлы
```
