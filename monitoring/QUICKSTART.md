# 🚀 Быстрый старт системы мониторинга логов

## Запуск

```bash
# Запустить все сервисы включая мониторинг
docker-compose up -d

# Проверить статус сервисов мониторинга
docker-compose ps loki promtail grafana

# Просмотр логов сервисов мониторинга
docker-compose logs -f loki
docker-compose logs -f promtail
docker-compose logs -f grafana
```

## Доступ

- **Grafana**: http://localhost:3001
  - Логин: `admin`
  - Пароль: `admin`
  - ⚠️ **Важно**: Измените пароль при первом входе!

- **Loki API**: http://localhost:3100

## Первые шаги в Grafana

1. Откройте http://localhost:3001
2. Войдите с учетными данными (admin/admin)
3. Перейдите в **Dashboards** (иконка папки в левом меню)
4. Откройте дашборд **"Логи всех сервисов"**
5. Или используйте **Explore** для кастомных запросов:
   - Перейдите в **Explore** (иконка компаса)
   - Выберите источник данных **Loki**
   - Введите запрос: `{job=~".+"}`
   - Нажмите **Run query**

## Особенности дашборда

- **Логи отображаются снизу вверх** - новые логи появляются внизу, старые сверху
- **Автообновление каждые 5 секунд** - дашборд автоматически обновляется для просмотра актуальных логов
- **Автоскролл** - при обновлении дашборд автоматически прокручивается к новым логам

## Полезные запросы

```logql
# Все логи
{job=~".+"}

# Логи конкретного сервиса
{job="user-service"}

# Ошибки (case-insensitive поиск)
{job=~".+"} |~ "(?i)(error|exception|failed|fail|critical|traceback|stack|panic|warn|warning)"

# Логи за последний час
{job=~".+"} [1h]
```

## Устранение проблем

### Promtail не собирает логи

1. Проверьте метки контейнеров:
```bash
docker inspect user_service | grep -A 5 Labels
```

2. Проверьте логи Promtail:
```bash
docker-compose logs promtail
```

### Grafana не показывает логи

1. Проверьте источник данных:
   - **Configuration** → **Data sources** → **Loki**
   - URL: `http://loki:3100`
   - Нажмите **Save & test**

2. Проверьте запрос:
   - Используйте простой запрос: `{job=~".+"}`
