# Дизайн-система «Матрикс» (редизайн под хакатон MAX)

## Направления, которые рассматривались

| # | Направление | Плюсы | Минусы | Итог |
|---|---|---|---|---|
| 1 | **Минимализм вокруг 3D-героя**: нейтральный графитовый фон, один бирюзовый акцент, мягкий свет только за персонажем | Персонаж — главный визуальный элемент; UI не спорит с разными сетами окружения; взрослый и опрятный вид | Меньше «игровой» эмоции в самих контролах — её даёт анимация персонажа | **Выбрано** |
| 2 | Взрослый игровой стиль: тёмная тема, неоновые/glow-акценты, HUD-подача цифр | Эмоционально, «геймерски» | Риск перегруза; неон конфликтует с цветными окружениями; хуже контраст текста | Отклонено |
| 3 | Нативный MAX UI (библиотека компонентов MAX) | Выглядит как часть мессенджера | Теряется узнаваемость продукта; веб-версия вне MAX выглядит «чужой»; меньше контроля над 3D-сценой | Отклонено |

Дополнительный приём ровно один — **мягкий радиальный градиент за персонажем** (без неона, без glassmorphism).

## Палитра и роли цветов

Все цвета заданы токенами в `frontend/src/styles/tokens.css`. Тёмная тема по умолчанию; светлая включается автоматически по `WebApp.colorScheme` (MAX) или `prefers-color-scheme`, либо атрибутом `data-theme="light"`.

|---|---|---|---|---|
| Фон | `--color-bg` | `#0E1116` | `#F5F7F9` | Фон приложения |
| Поверхность | `--color-surface` | `#161B22` | `#FFFFFF` | Карточки, шапка, нижняя навигация |

| Граница | `--color-border` | `#2A333F` | `#DCE1E7` | Обводки карточек и полей |
| Текст | `--color-text` | `#E8ECF1` | `#12171D` | Основной текст |

Старые переменные (`--primary-color`, `--bg-card` и т. д.) переопределены через новые токены, поэтому все существующие экраны получили новую палитру централизованно, без правок каждого файла.

Контраст проверен по WCAG 2.1: текст ≥ 4.5:1 на своих поверхностях (белый на primary — 5.2:1, приглушённый текст на поверхностях — ≥ 5:1).

## Типографика

* Заголовки — **Manrope** (600–800), текст — **Inter** (400–600), с системным fallback.
* Шкала: `--text-xs 12` · `--text-sm 14` · `--text-md 16` (тело) · `--text-lg 18` · `--text-xl 22` (заголовок экрана) · `--text-2xl 28` (крупные числа).
* Цифры параметров — `font-variant-numeric: tabular-nums`, чтобы не «прыгали».

## Компоненты (UI-кит `frontend/src/components/ui/`)

`Button` (primary / secondary / ghost / danger, размеры sm/md/lg, состояние loading), `Card`, `Badge`, `ProgressBar`, `Spinner`, `Skeleton`, `StateView` (loading / error с «Повторить» / empty), `Toast` (глобальные уведомления), `Modal` (на CSS-классах, закрытие по Esc/фону и кнопке «Назад» MAX).

Скругления: 8 / 12 / 16 / 22 px. Тени — одна мягкая (`--shadow-md`), обводка 1px. Состояния: hover — подсветка поверхности, active — сжатие 0.98, disabled — 50% прозрачности, focus — кольцо 3px цвета primary.

## Визуальный приоритет основного сценария

1. Первый экран «Сегодня»: 3D-персонаж занимает верхнюю часть экрана.
2. Под ним одна карточка текущей пары с единственной крупной primary-кнопкой «Отметиться» (сканер QR в MAX или ввод кода).
3. После отметки: анимация персонажа (танец + «+N» награды), тост успеха, обновлённые шкалы, уведомление в чате MAX.
4. Вторичные разделы (магазин, соцсеть, соревнования, события, статистика) — в «Ещё», визуально ровные.
